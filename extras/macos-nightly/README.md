# Ночной автопрогон (macOS, launchd)

Каждую ночь запускает выгрузку для всех аккаунтов из `nightly.conf` и к утру пишет отчёт
`ОТЧЁТ-последний-прогон.txt` рядом с папками назначения.

```bash
cd extras/macos-nightly
cp nightly.conf.example nightly.conf   # впиши свои профили и папки
./install.sh            # каждый день в 01:00   (./install.sh 3 30 — в 03:30)
launchctl kickstart gui/$(id -u)/ydisk-web-backup.nightly   # проверить сразу
./install.sh --remove   # отключить
```

Условия:
- Mac не должен спать ночью (настройки энергосбережения, или `sudo pmset repeat wakeorpoweron MTWRFSU 00:58:00`). Во время самого прогона сон блокирует `caffeinate`.
- Репозиторий должен лежать вне `~/Documents`, `~/Desktop` и `~/Downloads` (например, в `~/ydisk-web-backup`): macOS не пускает в эти папки фоновые задачи, и launchd не прочитает скрипт (`can't open input file`). `install.sh` это проверяет. **Не выдавайте `/bin/zsh` «Полный доступ к диску»** ради этого — такой доступ получит любой zsh-скрипт на компьютере. Если уже выдали — уберите (Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску).
- Сессии Яндекса должны быть уже сохранены в профилях (хотя бы один ручной запуск с входом для каждого профиля).

Linux: тот же `nightly.sh` можно повесить в `cron` (убрать строку с `caffeinate`).
